# rxsync-guardian

## Goal

rxsync-guardian looks for prescriptions that should not both exist. Pharmacy data
arrives from several systems that rarely agree with each other, so the same
prescription can show up twice under slightly different spellings, and the same
prescription can drift out of sync across sources -- different quantity, different
directions, different fill status, different prescriber. This project generates a
realistic stream of prescription records, normalizes them into a comparable shape,
flags the duplicates and the out-of-sync pairs, and explains in plain language why
each one was flagged, so a pharmacist can act on it. **All data used here is
synthetic** -- generated by the `simulator` package with Faker. No real patient or
prescription data ever enters this repository.

## Running it

Requires [uv](https://docs.astral.sh/uv/) and Docker.

```bash
cp .env.example .env        # then edit POSTGRES_PASSWORD if you like
docker compose up -d        # PostgreSQL 16 on localhost:5433
uv sync                     # creates .venv with Python 3.12 and all dependencies
uv run pytest               # verifies the database connection
```

`uv run pytest` should report one passing test; that confirms the container is up
and `DATABASE_URL` resolves. Other useful commands:

```bash
uv run ruff check .         # lint
uv run ruff format .        # format
docker compose ps           # container status, including health
docker compose logs -f postgres
docker compose down         # stop the database (the named volume is kept)
docker compose down -v      # stop it and delete the stored data
```

The host port is **5433**, not the default 5432, so the container can coexist
with a PostgreSQL install already running natively on this machine. Inside the
container (and inside the compose network) it is still 5432.

To open a psql shell against the running database:

```bash
docker compose exec postgres psql -U rxsync -d rxsync
```

## Layout

| Path | Holds |
| --- | --- |
| `simulator/` | Synthetic prescription event generation |
| `normalizer/` | Canonicalizing drug, patient, prescriber, pharmacy fields |
| `dedup/` | Duplicate-prescription detection |
| `desync/` | Out-of-sync detection between sources |
| `explainer/` | Human-readable reasons for each flag |
| `api/` | Service layer exposing detection results |
| `copilot/` | LLM-assisted review helpers |
| `evals/` | Accuracy and regression harness |
| `dashboard/` | Front end for reviewing flagged prescriptions |
| `infra/` | Deployment and database setup |
| `specs/` | Detection rules and data contracts |
| `data/raw/` | Generated datasets (gitignored) |
| `docs/` | Design notes |
| `tests/` | Test suite |

Every package is a placeholder at this stage -- the skeleton runs, but no detection
logic is implemented yet.
